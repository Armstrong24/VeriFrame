What the model relies on

Architecture

  1. v1+ Training: same 1,299 videos and features as v1; regularisation picked on validation, block-wise late fusion (one model per modality + meta-learner) and a fusion transformer whose caption token can be masked, giving a true video-only mode when the caption is empty.
  2. v2 Speech: Whisper base.en transcript of the narration → CLIP + MiniLM embeddings.
  3. v2 Audio: CLAP embedding of the soundtrack + loudness, speech ratio and zero-shot audio-type scores (speech / music / broadcast / crowd / silence).
  4. v2 Consistency: caption↔speech, speech↔frame and caption↔audio agreement scores; missing modalities are flagged, not guessed.
  5. v2 CGTF: Consistency-Guided Tri-Modal Fusion transformer over frame, caption, speech, audio and bio tokens with modality dropout, so one network also works with no caption.
  6. Video: 8 uniformly sampled frames → CLIP ViT-B/32 embeddings, plus editing statistics (shot cuts, motion, duration, resolution, sharpness).
  7. Text: caption → CLIP text embedding + MiniLM sentence embedding + style features (hashtags, caps, clickbait words, emojis).
  8. Cross-modal: per-frame caption-frame CLIP similarity, temporal embedding drift, element-wise text×video interaction.
  9. Models: Logistic Regression, RBF-SVM, LightGBM, XGBoost and the CGTF network (5-seed average).
  10. Ensemble: weighted soft-vote; weights and decision threshold tuned on the validation split for macro-F1.
VeriFrame · research prototype · predictions are probabilistic and should not be treated as fact-checks.
